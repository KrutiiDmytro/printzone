## Project Overview

Symfony 7.4 e-commerce application (electronics shop) with PHP 8.2+, PostgreSQL 16, and AWS S3 file storage abstraction via League Flysystem. Uses API Platform for REST endpoints and EasyAdmin for the admin interface.

## Development Environment

All commands run inside Docker containers:

```bash
docker compose build php
docker compose up -d
docker compose exec php composer install
docker compose exec php php bin/console doctrine:migrations:migrate --no-interaction
docker compose exec php php bin/console doctrine:fixtures:load --no-interaction
docker compose exec php php bin/console lexik:jwt:generate-keypair
```

Services: `php` (PHP 8.2-FPM), `database` (PostgreSQL 16), `nginx`, `mailpit`.

## Testing

```bash
# Run all tests
docker compose exec php php bin/phpunit

# Run a specific test suite
docker compose exec php php bin/phpunit --testsuite Unit
docker compose exec php php bin/phpunit --testsuite Functional

# Run a specific directory or file
docker compose exec php php bin/phpunit tests/Unit/Storage/
docker compose exec php php bin/phpunit tests/Functional/Admin/
```

Test suites are defined in `phpunit.dist.xml`. Use `.env.test` for test environment — it uses an in-memory SQLite DB.

## Environment Variables

Key variables in `.env` / `.env.local`:

```
STORAGE_TYPE=local          # or "s3" — controls FileStorageFactory backend
AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=
AWS_DEFAULT_REGION=eu-north-1
AWS_S3_BUCKET=
DATABASE_URL=postgresql://app:changeme@database:5432/app?serverVersion=16&charset=utf8
```

Full setup guide for S3 is in `docs/STORAGE_SETUP.md`.

## Architecture

### Module Structure (`src/`)

The app uses a modular monolith with DDD conventions:

- **Catalog** — `Product`, `Category`, `ProductSpecification` entities; domain lives in `Catalog/Domain/Entity/`
- **Cart** — `Cart`, `CartItem` entities + `CartService`; domain in `Cart/Domain/Entity/`
- **Order** — `Order`, `OrderItem` with status lifecycle (PENDING → PAID → PROCESSING → SHIPPED → DELIVERED)
- **User** — `User` entity with OAuth integration (Google, GitHub)
- **Storage** — File storage abstraction (see below)
- **Controller/Admin** — EasyAdmin CRUD with presigned S3 upload support
- **ApiResource** — API Platform resource definitions (OpenAPI/Swagger at `/api/docs`)

### Storage Module (`src/Storage/`)

Core abstraction for Task 22:

- `FileStorageInterface` — defines `write`, `read`, `delete`, `exists`, `listKeys`, `publicUrl`
- `FlysystemFileStorage` — implementation backed by League Flysystem
- `FileStorageFactory` — selects local or S3 adapter based on `STORAGE_TYPE` env var

Configured in `config/packages/storage.yaml` and `config/packages/aws.yaml`. `FileStorageFactory` is excluded from Symfony autowiring — it is manually wired in `services.yaml`.

Images are served via `GET /media?key=...` (MediaController). EasyAdmin uploads use presigned S3 URLs generated by `ProductImagePresignService`; the frontend logic is in `public/js/admin-product-image-s3.js`.

### Authentication

- JWT (LexikJWT) for API endpoints
- Session + OAuth 2.0 (Google, GitHub) for web
- Roles: `ROLE_USER`, `ROLE_ADMIN`
